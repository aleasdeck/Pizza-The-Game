# Пицца: Последняя неделя

Браузерный пиксельный рогалик-автобатлер. Курьер отрабатывает последнюю неделю перед пенсией: выбирает заказы, собирает пиццу и подаёт её на «застолье», где каждый гость ест ближайший к себе кусок.

Концепт-документ: https://claude.ai/artifact/1aXZ4GfJrFqFtYSPCHQ4eM

## Запуск

Сборки нет, это статические файлы и ES-модули.

```sh
npm start          # python3 -m http.server 8000, затем открыть http://localhost:8000
npm test           # юнит-тесты симуляции и забега (Node 20+)
npm run balance    # бот играет 30 недель и печатает средние оценки по дням
```

## Структура

| Файл | Что внутри |
| --- | --- |
| `src/data.js` | Топинги, тесто, бортики, рецепты, заказчики, районы, боссы, события, отзывы |
| `src/sim.js` | Симуляция застолья и подсчёт оценки, без DOM |
| `src/run.js` | Забег: неделя, доска заказов, магазин, награды, пенсия, улучшения пиццерии |
| `src/gfx.js` | Пиксельный движок: объёмная заливка, генератор людей, топинги |
| `src/views.js` | Сцены: пицца сверху, комната со столом, ночной город |
| `src/main.js` | Экраны и сохранения в localStorage |
